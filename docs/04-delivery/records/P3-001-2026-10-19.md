# Catatan Hasil P3-001 — Course dan Lesson

- Pelaksanaan dimulai: 2026-10-19; verifikasi lokal terakhir: 2026-10-21 WITA.
- Branch fitur: `feature/p3-001-course-lessons`, target integrasi `development`.
- Status: implementasi dan verifikasi lokal lulus; menunggu review akhir branch dan CI database kosong sebelum siap merge.
- Lingkungan: Next.js, Node test runner, Playwright Chromium, Supabase/PostgreSQL lokal dengan fixture sintetis terisolasi.

## Perubahan

Model course/lesson, constraint, metadata lifecycle, RLS, grants dan audit database disertai endpoint sesi staf. Portal menyediakan tab Pelajari Alkitab bagi Admin/Editor, daftar course dan lesson berurutan, pencarian/filter, form Draft, penyuntingan, publikasi, arsip/pemulihan, serta konfirmasi hapus Admin.

Revisi Published mempertahankan status dan langsung berlaku bila induknya Published. Slug terkunci setelah publikasi pertama. Menarik course ke Draft/Arsip menyembunyikan semua lesson tanpa mengubah status anak. Nomor urut boleh bercelah dan harus unik. Course yang masih memiliki lesson ditolak saat dihapus. Isi lesson adalah teks berparagraf dan tidak dirender sebagai HTML.

Form bertahan ketika server/jaringan gagal dan meminta konfirmasi sebelum membuang perubahan. Kontrol baru memakai target sentuh minimal 44px; dialog mempertahankan bottom sheet mobile, konteks induk, dan fokus keyboard. Dropdown bersama mendukung ArrowUp/Down, Home/End, Enter, Tab dan Escape tanpa menutup modal induk; fokus kembali setelah penyimpanan status selesai. Label status singkat menjaga judul panjang tetap aman pada 320px.
