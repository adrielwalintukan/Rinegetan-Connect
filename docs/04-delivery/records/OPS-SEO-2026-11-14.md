# Catatan OPS-SEO — Sitemap, Robots, Canonical, dan Kartu Sosial

- **Tanggal:** 14 November 2026
- **Issue:** OPS-SEO (#72)
- **Perubahan kode:** PR #106 (squash ke `development`), PR #107 (rilis ke `main`), PR ini (`og:url` rute pembaca)
- **Persetujuan:** pemilik repository menyetujui squash merge, rilis ke production, dan perbaikan lanjutan sebelum tiap langkah dijalankan.

Catatan ini tidak memuat kredensial, token, atau data pribadi.

## Kondisi sebelum

Diukur pada `development` `e92f855` dan production `main` `4c13fed`:

| Pemeriksaan | Hasil sebelum |
| --- | --- |
| `/sitemap.xml` | 404, tidak ada berkas rute |
| `/robots.txt` | 404, tidak ada berkas rute |
| `rel="canonical"` | tidak ada di rute publik mana pun |
| `og:image` di 7 halaman publik | tidak ada, padahal `twitter:card=summary_large_image` |
| `og:url` di 7 halaman publik | tidak ada |
| `og:url` di `/pelajari-alkitab` | ada, karena halaman ini tidak mendeklarasikan `openGraph` sendiri |

Penyebab `og:url` hilang: setiap halaman publik mendeklarasikan `openGraph` sendiri, dan Next.js **menimpa** `openGraph` root, bukan menggabungkannya. Akibatnya `url` yang diset di `layout.tsx` tidak pernah sampai ke HTML kecuali pada halaman yang tidak punya `openGraph`.

## Yang diterapkan

| Berkas | Perubahan |
| --- | --- |
| `src/app/sitemap.ts` | sitemap dinamis dari `courses`/`course_lessons` berstatus Published, dibungkus `try` agar rute statis tetap tersaji saat DB tidak terjangkau |
| `src/app/robots.ts` | allow `/`, disallow `/staff/`, `/api/`, `/auth/`, plus `Host` dan `Sitemap` |
| 10 rute publik | `alternates.canonical` |
| 7 halaman publik + `layout.tsx` | `openGraph.url` dan `openGraph.images` |
| 3 rute `pelajari-alkitab` | `openGraph.url`, `title`, `description`, `images` (PR lanjutan) |
| `src/app/opengraph-image.tsx` | kartu 1200x630 dibuat saat build dengan `next/og`, palet navy `#0A2540` dan amber `#E5A93C` |
| `src/app/twitter-image.tsx` | mengekspor ulang komponen yang sama agar kedua tag sinkron tanpa berkas biner di repo |

`NEXT_PUBLIC_SITE_URL` tetap diutamakan; fallback domain di ketiga berkas adalah `https://gmahkrinegetan.web.id`.

Sebabnya ada di test: `check()` melakukan satu klik lalu langsung membaca `checked`, sementara checkbox itu controlled React sehingga ada jendela balapan mikro saat render ulang. Layout dua kolom (`lg:grid-cols-7`) membuat posisi elemen di 1440px berbeda dari 320–1024px.

## Batas dan tindak lanjut

- Rute `pelajari-alkitab/[courseSlug]` dan `/[lessonSlug]` belum dapat diuji runtime karena belum ada kursus Published di production. Perubahannya mengikuti pola yang sama dengan halaman katalog yang sudah terverifikasi.
- Rute `sekolah-sabat/[quarterId]` dan turunannya belum punya `canonical` maupun `openGraph` sendiri, sehingga mewarisi metadata root. Ini kondisi lama, di luar lingkup issue ini, dan layak menjadi issue terpisah.
- Pratinjau `og:image` pada scraper WhatsApp/Facebook belum diuji langsung; cache pratinjau scraper mungkin perlu di-refresh manual.
- Sitemap belum disubmit ke Google Search Console; langkahnya ada di [DEPLOYMENT-RUNBOOK](../DEPLOYMENT-RUNBOOK.md).
