## Keputusan pemilik (2026-10-25)

Lingkup Pelajari Alkitab saja (bukan Sekolah Sabat/Adventech); sumber berupa berkas JSON yang disiapkan staf dengan sumber dan lisensi diisi per impor; batas 2 MB dan 1-100 lesson; Editor/Admin mengimpor, hanya Admin menyetujui lisensi; slug course yang sudah dipakai ditolak; pendekatan staging terpisah, course dan lesson Draft dibuat hanya setelah persetujuan Admin.

## Perubahan

- Parser tunggal `lib/courses/imports.mjs` (format `rinegetan-course-import/1`, bahasa `id`, 2 MB, 1-100 lesson, batas teks sama dengan CMS, URL `https://`, BOM dibuang) dan `import-actions.mjs`.
- Rute staf `POST /api/staff/course-imports`; `/api/staff/course-imports/[id]` berupa GET (preview, staf aktif) dan POST (setujui/tolak, Admin).
- Migration aditif `20261025000000_p3_003_course_imports.sql`: tabel `course_imports`, constraint dan trigger penegak, RLS, audit tanpa payload, dan fungsi `approve_course_import` (SECURITY DEFINER, cek Admin, kunci baris, satu transaksi).
- UI tab Pelajari Alkitab: **Impor JSON**, daftar Impor, **Lihat preview** (teks), **Setujui**/**Tolak** (alasan wajib), label persetujuan oleh orang yang sama.
- Contoh berkas sintetis `docs/04-delivery/templates/course-import-example.json` (diuji lolos parser), panduan di CONTENT-OPERATIONS, `course_imports` di DATA-MODEL-AND-RLS, dan bagian impor course di SECURITY-PRIVACY. Tanpa dependency baru.

- Payload dan metadata impor disimpan permanen; pembersihan ditunda. Tinjau ulang bila penyimpanan database mendekati kuota paket.

Temuan review PR #86; diuji pgTAP.
- Fungsi SECURITY DEFINER melewati RLS `courses`; dijaga cek Admin eksplisit dan diuji pgTAP.
- Belum dirilis: migration belum diterapkan ke production. Pengujian Chromium; perangkat fisik, Safari, dan Firefox belum diuji.
