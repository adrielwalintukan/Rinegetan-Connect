# P4-002 - Mekanisme katalog Indonesia dengan gate tertutup

## Tindak lanjut: integrasi online nyata

Setelah hasil sintetis ditinjau, pemilik mengonfirmasi izin pemegang hak untuk fetch/display/cache server Indonesia dan menyetujui plan `2026-11-10-p4-002-live-catalog.md`. Bagian di bawah merekam tahap awal, bukan status izin online terkini. Tidak ada dokumen izin privat yang dipublikasikan. Offline tidak diaktifkan.

Sumber resmi nyata menggunakan `in`, bukan `id`; endpoint `/id/` ternyata mengembalikan HTML SPA. Probe adapter langsung pada 2026-11-10 berhasil menghasilkan Dewasa “Karunia Nubuat”, `in-2026-04`, 13 pelajaran, periode 26/09/2026–25/12/2026, source version ETag. Daftar seri Indonesia tidak membuktikan kelas anak/remaja; UI hanya menerbitkan Dewasa aktif. Tidak ada credits pada detail saat probe; sumber Adventech disebut eksplisit, tanpa mewariskan penulis/penerbit triwulan lain.

Loader katalog kini memakai cache hasil valid Next.js satu jam, key per tanggal Asia/Makassar, dengan fetch raw no-store. Error tidak dikembalikan sebagai keberhasilan cache. Metadata sumber/version/fetched_at dipertahankan; UI menampilkan periode, jumlah pelajaran, sumber/waktu fetch dan tautan resmi. Tidak ada reader internal, cover upstream, akses staf/database, perubahan grant atau offline.

RED/GREEN lanjutan: endpoint `in`, normalisasi sumber tanpa credits karangan, pemilihan periode aktif/batas WITA dan loader gagal pada implementasi lama, lalu lulus dengan adapter nyata. Dua test UI tambahan (periode/atribusi/tautan dan pesan gangguan tanpa klaim izin tertunda) RED lalu GREEN. Browser fixture merender komponen produksi dengan CSS build nyata untuk status unavailable/available, judul/atribusi panjang tanpa spasi pada 320/375/768/1024/1440px; fixture hanya di test, tanpa route produksi. Hasil quality gate akhir dan CI dicatat pada PR exact-HEAD.

## Keputusan dan batas

Verifikasi final setelah perbaikan review (2026-11-11): `npm run test:all` lulus typecheck, lint, build dan **450/450** test Node; browser publik **47/47** lulus (termasuk 10 fixture katalog). Build tidak mencantumkan `/sekolah-sabat` pada prerender manifest; HTTP nyata 200 dengan `private, no-cache, no-store`, tanpa `x-nextjs-cache`, dan judul/tautan sumber nyata tampil. Audit a11y langsung halaman nyata pada 320/1440px lulus aturan WCAG 2.2 AA tanpa violation, struktur/overflow benar, dan 12 perpindahan fokus keyboard desktop terlihat. Runner a11y existing tertahan menunggu `load` iframe Google Maps; audit pengganti memakai `DOMContentLoaded` tanpa memblokir/mengubah iframe. Suite a11y seluruh situs tidak diklaim lulus. Supabase lokal tidak aktif; integrasi layanan penuh tetap memerlukan hasil CI.

Review lanjutan menemukan satu Important: Full Route Cache ISR dapat melewati perhitungan tanggal WITA pada loader. Test route RED membuktikan katalog dipanggil sebelum boundary request; perbaikan memakai `await connection()` sebelum loading, bukan `force-dynamic` yang menonaktifkan cache data secara luas. Cache katalog eksplisit tetap dipertahankan. Build/HTTP route diverifikasi dinamis; simulasi kalender pada proses Next produksi tidak dijalankan, batas tanggal diuji pada selektor dan boundary request diuji melalui route asli dengan dependency boundary.

Regresi database disposable lanjutan lulus cache 10/10 dan RPC 37/37, tanpa migration baru; cluster khusus dihentikan. Quality gate sebelum perbaikan review lulus 450/450, typecheck/lint/build. Probe halaman Next nyata menampilkan judul/periode/13 pelajaran/sumber/tautan; screenshot mobile bagian materi diperiksa. Test browser sempat gagal karena loader ESM di runner CJS dan stylesheet terblokir CSP warisan dokumen ketika memakai `setContent`; fixture kini dilayani via intercept Playwright pada dokumen baru tanpa route server produksi, dan 10/10 skenario katalog lulus. Tidak melemahkan CSP produk.

Pemilik menyetujui pilihan A, lalu rencana implementasi pada 2026-11-10: bangun mekanisme katalog secara sintetis sambil mempertahankan gate izin tertutup. Pemilik mengizinkan penyesuaian kartu agar lebih rapi dan mengutamakan mobile. Empat kelas jemaat, usia, deskripsi, waktu, jadwal dan media tetap dipertahankan; kelas jemaat bukan pemetaan kelas materi Adventech.

## Implementasi

- `selectSabbathCatalog(entries)` menormalisasi ulang payload quarterly mentah memakai validator existing, menerima hanya lima identitas kelas tepercaya, dan mengurutkan Kindergarten, Primary, PowerPoint, Cornerstone, Dewasa. Kelas tidak tersedia, asing, invalid atau duplikat disembunyikan. Dewasa hanya tampil jika valid; tidak ada terjemahan/fallback karangan.
- `loadSabbathCatalog()` server-only tetap unavailable/classes kosong dan tidak mengambil sumber atau membuka koneksi database. Selektor dan cabang render tersedia diuji dengan data sintetis; belum ada caller produksi yang mengaktifkannya. Tidak ada fixture diterbitkan ke publik.
- Route publik memuat status katalog bersama jadwal/media. Bagian “Materi Sekolah Sabat” terpisah dari kelas jemaat, dengan pesan belum tersedia. Cabang tersedia menampilkan judul/atribusi sebagai teks React, tanpa HTML aktif, cover, reader atau tautan palsu.
- Kartu lokal memakai metadata usia, judul/deskripsi yang lebih jelas dan satu kolom mobile/dua kolom saat ruang cukup. Tidak ada ikon buku berulang, warna/dependency baru, carousel, atau perubahan data pelayanan. Jadwal memakai dua kolom yang dapat membungkus teks di layar kecil.
- Tidak ada migration, perubahan grants/RLS, pembukaan gate, request materi nyata, reader, offline, akun Member atau progres cloud.

## Bukti pengujian

- RED selektor: empat test gagal saat fungsi belum tersedia; GREEN empat test lulus setelah selektor ditambahkan.
- RED loader: assertion export katalog gagal; GREEN test membuktikan unavailable/classes kosong dan nol fetch/koneksi, sambil mempertahankan pembatasan loader quarterly.
- RED halaman: empat test gagal karena bagian materi dan prop route belum ada; GREEN membuktikan informasi lokal utuh, urutan kelas dan atribusi sintetis aman, gate tertutup mengabaikan entri, serta route memakai loader.
- `npm run test:all` akhir lulus: typecheck, lint, build dan suite Node 443/443, 0 skip.
- PostgreSQL 18.6 UTF-8 disposable baru, fixture Auth/staf minimal, tiga migration cache existing diterapkan berurutan. pgTAP 1.3.3 dipasang hanya dalam database disposable dari sumber resmi (bukan ekstensi sistem). Tes cache 10/10 dan RPC 37/37 lulus; gate diverifikasi false sesudah rollback, lalu cluster dihentikan. Ini bukan pengganti verifikasi Auth/Supabase lengkap di CI. Database/proses proyek lain tidak disentuh.
- Playwright Chromium: suite route publik lulus 42/42, termasuk katalog pada 320/375/768/1024/1440px (kelas lokal, tanpa overflow/tab/aksi/cover materi atau request host Adventech). Suite a11y lokal lulus 28/28: WCAG AA mobile/desktop, fokus keyboard dan reduced motion. Screenshot baseline beranda dan snapshot performa production tidak dijalankan.
- Screenshot mobile/desktop diperiksa lokal. Capture awal sebelum scroll belum memicu Reveal pada bagian bawah; diagnosis membuktikan opacity 0 sebelum viewport dan 1 setelah scroll dengan tinggi tetap. Capture sesudah scroll memperlihatkan keempat kelas, materi unavailable, jadwal, media dan banner tanpa ruang konten hilang; tidak mengubah komponen animasi global.
- Build selesai, tetapi melaporkan koneksi Supabase lokal port 54321 tidak aktif; bukan bukti integrasi layanan. Percobaan quality gate foreground awal timeout saat build; build terpisah berhasil, quality gate akhir dan CI harus diverifikasi tersendiri.
- Pint/PHPStan/Vitest tidak berlaku: produk memakai Next.js/Supabase dan Node test runner; tidak ada Composer atau tooling tersebut. Tidak menambah dependency agar menyerupai stack lain.

## Review

Review independen seluruh diff tidak menemukan Critical/Important dan menjalankan ulang sembilan test terarah (9/9 lulus). Satu minor ditunda: pembungkusan judul/atribusi sintetis panjang pada cabang available belum diuji di browser 320px; cabang itu belum dapat dicapai produksi. Browser telah menguji katalog unavailable dan empat kelas lokal pada seluruh ukuran di atas; escaping teks cabang available diuji di Node. Tambahkan browser fixture panjang sebelum aktivasi katalog nyata.
