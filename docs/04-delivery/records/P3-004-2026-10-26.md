## Batas dan risiko

- Turnstile production memakai widget Cloudflare dengan hostname `rinegetan-connect.vercel.app` saja. Preview deployment tidak tercakup hostname itu, jadi Preview memakai test key Cloudflare dan tidak dapat menulis data karena `SUPABASE_SECRET_KEY` hanya di-scope Production. Saat domain baru dipasang, tambahkan hostname itu ke widget; site key dan secret key tidak berubah.
- Rate limit memakai entri pertama `x-forwarded-for` yang ditulis Vercel; di lingkungan lain header dapat dipalsukan sehingga rate limit melemah, tetapi Turnstile tetap wajib.
- Tes e2e bergantung pada jaringan ke Cloudflare (widget dan siteverify dengan test key).
- Tidak ada delete, ekspor, atau notifikasi email (P3-006/di luar lingkup). Pengujian browser hanya Chromium.
