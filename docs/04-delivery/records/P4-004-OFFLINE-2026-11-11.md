# P4-004 (issue #53) — Kontrak paket lokal dan gate tertutup (2026-11-11)

**Status:** Kontrak manifest siap; **gate aktivasi belum lulus**, fitur unduhan/offline tidak dirilis.

Issue: [#53](https://github.com/adrielwalintukan/Rinegetan-Connect/issues/53). Branch `feature/p4-004-offline-manifest`.

**Catatan penamaan:** repo ini sudah memakai nama `P4-004-2026-11-11.md` untuk record popup ayat (pekerjaan P4-003 lanjutan, PR #96). Record ini memakai akhiran `-OFFLINE` agar tidak menimpa riwayat itu.

## Batas yang menentukan bentuk pekerjaan ini

Issue #53 memisahkan dua hal: "mekanisme teknis dapat disiapkan, aktivasi materi publik bersyarat hak P4-005". Acceptance kelima menambahkan syarat tegas: "tombol download/offline nonaktif/tidak dirilis sebelum gate izin P4-005". Blocker issue ini juga menyebut format arsip/protokol paket dan library-nya belum diputuskan.

Karena itu pekerjaan ini hanya menetapkan bagian kontrak yang sudah diputuskan, dan tidak mengarang yang belum. Yang **tidak** dibuat: format arsip, skema IndexedDB, transport unduhan, dan UI unduhan. Membuat salah satunya berarti mengubah keputusan pemilik menjadi asumsi implementer, dan langsung melanggar acceptance kelima.

## Yang dikerjakan

Modul `frontend/src/lib/sabbath/offline.mjs`:

| Fungsi | Perannya |
| --- | --- |
| `OFFLINE_ENABLED`, `offlineEnabled()` | Gate sebagai konstanta modul. Bukan parameter fungsi, sehingga tidak ada pemanggil yang bisa menyalakannya dengan argumen. |
| `createManifest()` | Membangun manifest dari ID triwulan/lesson yang lolos pola reader; menolak metadata invalid dengan `null`, bukan manifest separuh jadi. |
| `parseManifest()` | Membangun ulang manifest dari storage. Bentuk objek tersimpan tidak dipercaya; label tersimpan harus sama dengan label turunan, sehingga file yang disunting tangan ditolak. |
| `updateAvailable()` | Membandingkan versi untuk triwulan yang sama, hanya untuk menghasilkan pesan "Update tersedia". Tidak ada unduhan otomatis. |
| `carryProgress()` | Mempertahankan progres hanya untuk lesson yang masih ada di paket baru, memakai kunci `quarter/lesson/day` yang sama dengan catatan P4-006. |

Manifest memuat `version`, `sizeBytes`, `createdAt`, dan `label` yang terlihat — acceptance pertama issue #53. Label diturunkan dari data, tidak disimpan sebagai sumber kebenaran terpisah.

## Keputusan yang masih menunggu pemilik

1. **Format arsip/protokol paket dan library.** Tanpa ini, `sizeBytes` hanya masukan pemanggil, bukan hasil pengukuran paket nyata. Tidak ada paket yang bisa dibangun.
2. **Skema IndexedDB dan transport unduhan.** Keduanya turunan langsung dari format arsip.
3. **Cakupan izin offline.** P4-005 masih gate eksternal; konfirmasi 2026-11-10 hanya mencakup fetch, penayangan, dan cache server.

Ketiganya dicatat sebagai keputusan yang diperlukan, bukan diisi dengan nilai karangan.
