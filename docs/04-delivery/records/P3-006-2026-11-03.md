## Keputusan pemilik (2026-11-03)

- **Retensi tetap 24 bulan, tanpa UI ubah retensi.** Acceptance 1 ("Admin dapat mengubah retensi") bertentangan dengan keputusan pemilik 2026-11-01 (review PR #88): retensi tidak dapat diperpanjang untuk data dengan copy "paling lama 24 bulan". Periode lain hanya untuk pengumpulan baru dengan versi consent baru yang disahkan, lewat issue terpisah. Tidak ada periode alternatif.
- **Penghapusan:** tombol Admin di portal, dijalankan mingguan. Tidak ada penjadwal otomatis; SQL runbook menjadi cadangan.
- **Ekspor:** tidak disediakan di P3-006.
- **Status:** tetap memakai status P3-004/P3-005.
- **Audit akses:** satu `pastoral.viewed` per muat portal Admin, berisi jumlah saja. Audit ini ditampilkan terpisah dari linimasa 50 entri.

## Perubahan

- Migration aditif `20261103010000_p3_006_pastoral_retention.sql` berisi `private.pastoral_retention_cutoff()`, `public.expired_pastoral_counts()`, `public.purge_expired_pastoral_data()`, dan `public.record_pastoral_access(int, int, int)`. Semuanya SECURITY DEFINER, `search_path` kosong, dan khusus Admin aktif, dengan execute dicabut dari `public`/`anon`/`service_role`. Migration tidak menambah tabel, kolom, atau grant `DELETE`.
- `lib/forms/pastoral-admin.mjs` mendapat `recordPastoralAccess`, `loadExpiredPastoralCounts`, dan `purgeExpiredPastoralData`. `lib/staff/audit.mjs` mengecualikan `pastoral.viewed` dari 50 entri utama dan memuat 20 entri akses terbaru secara terpisah.
- Route baru `POST /api/staff/pastoral-retention` mewajibkan JSON, memeriksa staf aktif sebelum tindakan, dan hanya untuk Admin.
- Portal staf: data minat belajar/doa/kunjungan hanya dikirim ke browser setelah audit akses berhasil ditulis (fail-closed). Tab Log Audit mendapat panel **Retensi data pastoral** (jumlah kedaluwarsa, tombol **Hapus data kedaluwarsa** dengan dialog konfirmasi yang sudah ada) dan daftar **Akses data pastoral**.
- Dokumen yang diperbarui: RETENTION-DELETION-RUNBOOK (prosedur portal, SQL sebagai cadangan), DATA-MODEL-AND-RLS, SECURITY-PRIVACY, CONTENT-OPERATIONS, ISSUE-BACKLOG (termasuk status merge P3-005 `5c31d55`), dan ROADMAP. Tidak ada dependency baru.
