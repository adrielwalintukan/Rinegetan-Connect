# P4-004 — Popup ayat di bacaan Sekolah Sabat

Tanggal: 2026-11-11 (Asia/Makassar). Lanjutan tinjauan pemilik pada PR #96. Issue #52 tetap terbuka.

## Permintaan

Di bacaan harian Sekolah Sabat, referensi ayat seperti “Mat. 7: 5” dapat diklik dan menampilkan popup berisi bunyi ayat tersebut.

## Sumber bunyi ayat

Respons `…/days/<day>/read/index.json` sudah memuat `bible`, yaitu array `{ name, verses }` berisi bunyi ayat untuk referensi yang dipakai hari itu. Jadi fitur ini **tidak menambah request baru** dan tidak memanggil API Alkitab pihak ketiga.

Probe pada 5 pelajaran triwulan `2026-04` (35 hari): 32 hari menyertakan `bible`, 198 referensi di konten, dan 198 di antaranya punya bunyi ayat — tidak ada referensi yang kehilangan teks. Nilai `verses` memakai tag `h2` (judul referensi) dan `sup` (nomor ayat) saja.

## Keamanan

- `verses` disanitasi dengan daftar tag konten tanpa `a`/`button` dan tanpa atribut apa pun; script/style/iframe/svg/img/event handler hilang.
- Referensi yang bunyi ayatnya tidak ada tetap teks biasa, jadi tidak muncul tombol yang tidak berbuat apa-apa.
- Tidak ada `dangerouslySetInnerHTML` baru tanpa sanitasi: HTML artikel dan HTML ayat sama-sama berasal dari normalizer server.

## Aksesibilitas

`<dialog>` native memberi focus trap, penutupan dengan Escape, dan pengembalian fokus ke tombol asal tanpa kode sendiri. Ada tombol tutup berlabel “Tutup ayat”, `aria-label` dialog memakai teks referensi yang diklik, dan backdrop dapat diklik untuk menutup.

- Pemeriksaan langsung di build produksi terhadap konten Adventech asli (`/sekolah-sabat/2026-04/07/05`): 4 referensi menjadi tombol, popup terbuka lewat klik dan Enter, Escape menutup dan mengembalikan fokus ke tombol asal, backdrop menutup, `body` scroll pulih, dialog panjang menggulir sendiri tanpa overflow halaman.
- axe pada halaman dengan popup terbuka dan tertutup di 320/375/1440px: tanpa violation WCAG 2.2 AA, tanpa overflow horizontal.

## Batas

- Popup hanya tersedia pada bacaan harian, karena hanya respons itu yang membawa `bible`. Daftar pelajaran dan daftar hari tidak memuat ayat.
- Teks ayat mengikuti terjemahan yang dipilih Adventech; aplikasi tidak menyediakan pemilih terjemahan.
- Bila upstream tidak mengirim `bible` untuk suatu hari, referensi tetap teks biasa — tidak ada fallback ke API Alkitab lain.
