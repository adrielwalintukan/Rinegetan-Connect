- **Tanggal:** 23 Oktober 2026

- **Acuan:** WCAG 2.2 AA (PRD bagian 6), kontrak desain (`docs/02-design/DESIGN-SYSTEM.md`), strategi test (`docs/06-quality/TEST-STRATEGY.md`)

Catatan ini tidak memuat project reference, email, URL privat, atau nilai kredensial.

## Cara audit

Spec Playwright baru `frontend/tests/visual/a11y-audit.spec.ts` (`npm run test:a11y`) memeriksa sembilan rute: `/`, `/tentang-kami`, `/kegiatan`, `/pelayanan`, `/media`, `/sekolah-sabat`, `/kontak`, `/pelajari-alkitab`, `/staff/login`.

- **Aturan axe-core 4.13.0** dengan tag `wcag2a`, `wcag2aa`, `wcag21a`, `wcag21aa`, `wcag22aa`, pada lebar 320px dan 1440px, dengan `prefers-reduced-motion: reduce`. Halaman digulir sampai akhir sebelum pengukuran agar semua animasi reveal selesai.
- **Struktur halaman:** tepat satu `<main>` dan satu `<h1>`, semua `<img>` memiliki atribut `alt`, tanpa overflow horizontal.
- **Fokus keyboard:** 12 kali Tab per rute; setiap elemen yang menerima fokus harus memiliki outline atau box-shadow yang terlihat.
- **Performa:** TTFB, LCP, CLS, dan ukuran transfer pada viewport 375px. Hanya dicatat, karena budget belum disepakati.

Target default adalah production (`AUDIT_BASE_URL` untuk mengganti). Spec ini belum masuk CI; integrasi dilacak di QA-CI-E2E (#73).

## Perbaikan

- Token `sabbath-600` → `#92661C` dan `sabbath-700` → `#785417` (hue amber sama, lebih gelap). Keduanya hanya dipakai sebagai warna teks; `sabbath-500` (#E5A93C) untuk CTA, aksen, dan kolom ketujuh tidak berubah.
- Outline `:focus-visible` memakai `#92661C`: ≥3:1 terhadap latar terang dan navy.
- `.label-eyebrow`, teks kecil denominasi di `EntityLockup`, dan keterangan Sabat di Hero memakai `slate-600`; "Bagian dari GMAHK sedunia" dari `slate-400` ke `slate-500`.
- `ChapterHeading` menerima `as`; judul utama enam halaman dirender sebagai `<h1>` tanpa perubahan tampilan.
- Layout publik dibungkus `<MotionConfig reducedMotion="user">`: animasi transform dimatikan bila pengguna meminta reduced motion. Lenis sudah menghormati preferensi ini sebelumnya.
- Regression test CI baru `frontend/tests/p1-002-a11y.test.mjs`: rasio kontras token, rasio cincin fokus, `MotionConfig`, dan satu `<h1>` per halaman.

## Hasil sesudah perbaikan

Build lokal (`next start`): **27/27 cek lulus** (18 axe + struktur, 9 fokus keyboard). Build lokal tidak terhubung ke database, sehingga bagian yang bergantung data (kegiatan, pengumuman, foto) tampil sebagai empty state. Audit ulang terhadap production setelah rilis diperlukan untuk menutup batas ini.

Quality gate: `npm run test:all` lulus, 239/239 test frontend.

## Snapshot performa (production, mobile 375px, bukan budget)

Tiga kali pengukuran dari Playwright Chromium di jaringan operator; angka bervariasi menurut cold start dan cache.

| --- | --- | --- | --- | --- |

| `/tentang-kami` | 0,26–1,4 s | 1,6–2,9 s | 1 KB | |
| `/kegiatan` | ~100 ms | 0,5–1,8 s | 3 KB | |
| `/pelayanan` | 90–690 ms | 0,4–1,0 s | 0 KB | |
| `/media` | 110–250 ms | 0,7–2,2 s | 6 KB | |
| `/sekolah-sabat` | 88 ms – 7,7 s | 0,4–8,9 s | 0 KB | Lonjakan saat regenerasi ISR (cache STALE); respons HIT sekitar 0,4 s |
| `/kontak` | ~100 ms | 0,3–0,9 s | 3 KB | |

CLS 0 di semua rute.

**Proxy media:** satu derivative Hero 449 KB melalui `/api/media/file/...` butuh 2,5–8,4 detik dan tidak pernah di-cache CDN (`Cache-Control: private, max-age=300`, `x-vercel-cache: MISS`).

## Keputusan yang masih diperlukan pemilik

1. **Budget performa:** angka LCP/TTFB/ukuran JS belum ditetapkan dokumen. Snapshot di atas bisa menjadi baseline.
2. **Cache proxy media:** cache publik di CDN akan mempercepat foto secara signifikan, tetapi foto yang ditarik (hide/Draft/consent dicabut) tetap tersaji sampai TTL habis. Ini trade-off privasi dan consent; tidak diubah tanpa keputusan.
3. **LCP Beranda:** menampilkan teks Hero sejak awal (animasi hanya transform) akan memperbaiki LCP tetapi mengubah koreografi intro. Perlu persetujuan sebelum diubah.

## Batas verifikasi

- Audit otomatis tidak menggantikan uji pembaca layar dan perangkat fisik (iOS Safari, Android Chrome). Belum dilakukan.
- Fokus di dalam iframe peta Google tidak diperiksa: indikator fokusnya digambar oleh halaman Google, bukan situs ini. Di Chromium headless, iframe lintas origin tidak pernah cocok dengan `:focus` maupun `:focus-within`, sehingga CSS situs tidak dapat menggambar cincin untuknya.
- Portal staf di luar `/staff/login` tidak diaudit di issue ini.
- Baseline screenshot `home-desktop.png` di `public-routes.spec.ts` dapat berbeda setelah perubahan warna token, dan perlu diperbarui pada environment baseline-nya.
