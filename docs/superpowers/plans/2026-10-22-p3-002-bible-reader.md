# P3-002 Reader Pelajari Alkitab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pengunjung membaca course/lesson publik tanpa akun, dengan navigasi, progres manual, bookmark, dan lanjut belajar pada browser lokal.

**Architecture:** Server Components mengambil proyeksi publik melalui client anonim dan cache reader khusus. Modul `.mjs` menangani query/progres/invalidation; Client Components hanya mengelola interaksi browser. Route CMS P3-001 menginvalidasi reader setelah mutasi tanpa mengubah database, lifecycle, atau audit.

**Tech Stack:** Next.js 16 App Router, React 19, TypeScript, Tailwind, Supabase, Node test runner, Playwright Chromium; tanpa dependency baru.

**Spec:** [Spesifikasi P3-002](../specs/2026-10-22-p3-002-bible-reader-design.md), disetujui tertulis oleh pemilik pada 2026-10-22.

## Global Constraints

- Branch `feature/p3-002-bible-reader`, dasar `development` pada `42a3d01`, menuju `development` melalui PR. Checkout aktif mengikuti arahan pemilik; jangan mengubah folder proyek lama.
- Publik tanpa akun. Query memakai client anonim tanpa cookie sesi/admin client; lesson hanya terbaca bila lesson dan course induknya Published.
- Proyeksi kolom publik eksplisit tanpa actor. Body lesson hanya dimuat pada halaman lesson, bukan dalam seluruh katalog atau daftar lesson.
- Rute `/pelajari-alkitab`, `/pelajari-alkitab/[courseSlug]`, `/pelajari-alkitab/[courseSlug]/[lessonSlug]`. Nomor urut boleh bercelah.
- Isi lesson tetap teks biasa: paragraf dan baris baru dipertahankan, HTML/Markdown tidak dieksekusi maupun dirender sebagai markup.
- Progres memakai tombol Tandai selesai dan Batalkan selesai. Membuka lesson hanya menyimpan posisi terakhir; bookmark menandai lesson, bukan posisi scroll.
- Progres/bookmark hanya lokal pada browser: ID course/lesson dan versi schema, tanpa body/judul/PII/credential atau kiriman ke server.
- Konten publik menggunakan cache/revalidate 60 detik. Invalidasi setelah mutasi CMS mencakup katalog, pola course/lesson dan tag reader dengan kedaluwarsa segera.
- Tidak menambah migration, perubahan RLS/audit, atau dependency. Tidak menambah impor, form minat/pastoral, akun Member, offline/PWA, atau integrasi Sekolah Sabat.
- UI Bahasa Indonesia, PageShell/Creation Grid/identitas resmi tetap; target sentuh minimal 44px, keyboard/fokus dan 320/375/768/1024/1440px tanpa overflow.
- Tidak ada secret nyata, akun production, pembacaan private key age, backup/rilis, SQL production, promote, atau merge development/main. Backup/persiapan rilis tetap ditunda pemilik.
- Jangan commit `.claude/`, `.ai-context/`, environment, backup, atau artefak test. Perintah manual untuk pemilik mengikuti PowerShell 5.1.
- Metode subagent per tugas sudah dipilih pemilik; satu implementer aktif, review terpisah tiap tugas, lalu review keseluruhan. Rencana disetujui pemilik pada 2026-10-22; implementasi mengikuti gerbang review dan CI.

## Review Focus

1. Cache telah berisi lesson ketika course induk ditarik/dihapus: request baru setelah mutasi CMS tidak mengembalikan salinan Published lama. Pemilik test: Task 3 dan 4.
2. localStorage melempar saat property diakses, JSON rusak, versi salah, atau kuota penuh: reader tetap terbaca dan tidak mengklaim persistensi berhasil. Pemilik: Task 2 dan 4.
3. Progres memuat ID lesson yang ditarik/dihapus dan posisi bercelah: denominator hanya lesson publik, lanjut belajar tidak menautkan materi tersembunyi, membuka halaman tidak auto-complete. Pemilik: Task 2 dan 4.
4. Mutasi committed tetapi invalidasi melempar: response tetap sukses dengan peringatan aman, tidak ada mutasi ulang dan form tidak menyatakan gagal simpan. Pemilik: Task 3 dan 4.
5. Katalog/lesson melampaui 1.000 baris, halaman query lanjutan gagal, atau slug lesson sama pada dua course: tidak ada pemotongan/hasil parsial/pertukaran induk. Pemilik: Task 1 dan 4.

## Referensi API yang diperiksa

- [Next.js connection](https://nextjs.org/docs/app/api-reference/functions/connection): menunda rendering hingga request, sehingga query reader tidak wajib berhasil saat build.
- [Next.js fetch](https://nextjs.org/docs/app/api-reference/functions/fetch): cache GET eksplisit dengan lifetime/tag; hanya respons sukses yang dipakai sebagai konten cache.
- [Cache tanpa Cache Components](https://nextjs.org/docs/app/guides/caching-without-cache-components): force-dynamic memaksa fetch tidak dicache, sehingga tidak dipakai untuk reader ini.

Perilaku/signature juga diperiksa pada source Next.js 16.3.4 yang terpasang; dokumentasi web dapat menampilkan versi lebih baru. Tidak mengaktifkan Cache Components atau mengubah next.config.
