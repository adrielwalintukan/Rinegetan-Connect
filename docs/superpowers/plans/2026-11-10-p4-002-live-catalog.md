# Live Indonesian Catalog Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mengganti katalog kosong dengan metadata materi Indonesia nyata setelah pemilik mengonfirmasi izin fetch, penayangan dan cache server.

**Architecture:** Loader server mengambil quarterly Indonesia dari Adventech dengan kode upstream `in`, memilih triwulan berjalan, memvalidasi sebelum menyimpan hasil dalam cache server Next.js selama satu jam. Katalog menampilkan hanya kelas yang terbukti tersedia, dengan atribusi sumber dan tautan ke situs resmi. RPC PostgreSQL Admin existing tetap tertutup; tidak ada reader internal atau offline dalam perubahan ini.

**Tech Stack:** Next.js, React, Node test runner, Playwright; tanpa dependency baru.

**Spec:** Konfirmasi pemilik pada percakapan 2026-11-10; issue #51; docs/05-integrations/SABBATH-SCHOOL-ADVENTECH.md. Plan ini menggantikan asumsi gate katalog tertutup dalam plan sintetis terdahulu, bukan membuka izin offline.

## Global Constraints

- Branch/PR #95 existing, tanpa clone/worktree/merge; jangan menyentuh `remotion/`.
- Jangan unggah dokumen izin privat, identitas kredensial, nama AI atau path lokal ke GitHub.
- Kelas jemaat lokal tetap terpisah dan utuh. Tidak ada fallback bahasa, kelas atau atribusi penerbit karangan.
- Izin fetch/display/cache server sudah dikonfirmasi; register administratif hak tetap milik gereja. Offline tidak diaktifkan.

## Source Evidence

- `https://sabbath-school.adventech.io/api/v2/in/quarterlies/index.json` mengembalikan JSON; `/id/` mengembalikan HTML SPA, bukan API JSON.
- Detail `in/quarterlies/2026-04/index.json`: `lang: in`, `index: in-2026-04`, judul “Karunia Nubuat”, 13 pelajaran, periode 26/09/2026–25/12/2026; ETag dan Last-Modified tersedia.
- Daftar Indonesia yang diperiksa hanya memiliki seri quarterly tanpa kelompok anak/remaja. Pendahuluan 2026-04 menyebut Pedoman Pendalaman Alkitab Sekolah Sabat Dewasa, mengonfirmasi pemetaan seri ini ke Dewasa.
- Detail 2026-04 tidak menyertakan credits; `src/in/credits.yml` resmi berisi nilai kosong. Jangan mewariskan kredit penulis/penerbit triwulan lain. Cantumkan Adventech sebagai sumber teknis dengan tautan resmi, dan tampilkan credits hanya jika tersedia/valid.

## Review Focus

- HTML berstatus 200, redirect, payload terlalu besar atau JSON rusak harus ditolak.
- Triwulan lama/mendatang tidak boleh dipilih diam-diam; batas tanggal mengikuti Asia/Makassar.
- Respons bahasa/ID silang, pelajaran duplikat dan URL tidak tepercaya harus ditolak.
- Credits absen berbeda dengan credits rusak; jangan menciptakan identitas penerbit.
- Cache tidak boleh menyimpan hasil unavailable sebagai sukses atau memerlukan sesi staf; teks panjang harus membungkus pada 320px.
