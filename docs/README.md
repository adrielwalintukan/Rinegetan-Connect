## Keputusan utama

- Platform menggunakan Next.js App Router, TypeScript, dan Supabase.
- Peran saat ini hanya Admin dan Editor; tidak ada akun Member.
- Wilayah waktu operasional adalah Asia/Makassar (WITA).
- Project Supabase baru ditetapkan di Singapore; project Tokyo lama tidak diubah.
- Pilot memakai layanan tanpa biaya dalam batas yang telah ditetapkan.
- Sekolah Sabat offline harus menunggu izin tertulis pemegang hak materi.
